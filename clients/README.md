# Clients

Thin clients obeying Haven L7 file-CID rule set — no shared private DB.

- **Reference (stable, `video/*`-only today):** [haven-dapp](https://github.com/Haven-hvn/haven-dapp), [haven-cli](https://github.com/Haven-hvn/haven-cli), [haven-mobile](https://github.com/Haven-hvn/haven-mobile), [foc-local-first-android](https://github.com/Haven-hvn/foc-local-first-android) — see root `awesome.md`
- **Experimental (incubator):** [haven-clients-experimental](https://github.com/Haven-hvn/haven-clients-experimental) — SLOP testbed for `audio/*`, `image/*`, `pdf/epub`, `csv/parquet`, `safetensors`, `gltf`, etc. (`clients/<name>/` per client, merged PRs count under `haven`, graduates promote to standalone `Haven-hvn/<client>` repos/projects)
